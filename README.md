## 📱 How to Listen & Read

### 🤖 Android (Recommended: Smart AudioBook Player)
1. Download or clone this repository to your Android device (or transfer via USB).
2. Open **[Smart AudioBook Player](https://play.google.com/store/apps/details?id=ak.alizandro.smartaudiobookplayer)** (or **Voice Audiobook Player**).
3. Set your Audiobook root directory to the folder containing `Volume 1` through `Volume 6`.
4. The player automatically detects:
   - The embedded root `cover.jpg` artwork and individual `Volume X/cover.jpg` artworks.
   - Chapter titles, track numbers, and 4-digit zero-padded track sequences (`Chapter_0001`, `Chapter_0002`...).
   - Resume points and per-volume progress tracking without any manual configuration.

### 🍏 iOS / macOS
- **Audiobooks**: Use **[BookPlayer](https://apps.apple.com/app/bookplayer/id1138210298)** or **VLC for Mobile**. Transfer via AirDrop, iCloud Drive, or the Files app.
- **eBooks**: Add the `.epub` files from `eBook (Repaired Edition)/` directly into Apple **Books**.

### 💻 Windows / Linux
- **Audio**: Play with **[foobar2000](https://www.foobar2000.org/)**, **[VLC Media Player](https://www.videolan.org/vlc/)**, or **MusicBee** (native Opus support with full metadata tags).
- **eBooks**: Open with **Calibre**, **Thorium Reader**, or any browser EPUB reader.
